# rusanivsky.com

Статичний сайт. GitHub Pages віддає гілку `main` напряму — ніяких Actions і
збирачів немає. Що лежить у гілці, те й на сайті приблизно через 30 секунд
після пуша. Домен у `CNAME`, `.nojekyll` вимикає обробку Jekyll.

## Головне правило

**Каталог `ua/**` не редагується руками.** Це згенеровані файли.

Джерело — англійські сторінки (`index.html`, `rates/index.html`,
`photo/**`, `video/**`, `design/**`). Кожна з них двомовна: текст лежить
парою атрибутів `data-en` / `data-ua` на одному елементі, а перемикач у
шапці міняє `textContent`. Скрипт збирає з них українські копії, роблячи
українську мову вже відданою сервером, а не наслідком JavaScript.

Правка в `ua/**` живе рівно до наступного запуску білда.

## Білд

```bash
node scripts/build-ukrainian-pages.mjs
```

Перезбирає **всі** 16 українських сторінок з англійських джерел,
переписує голови самих англійських файлів (canonical, hreflang, og,
theme-color, посилання на умови роботи), перегенеровує `sitemap.xml` і
заглушки для сторінок, що переїхали (`/contacts/` → `/rates/`).

Ідемпотентний: другий прогін поспіль не змінює нічого. Якщо змінює —
десь розійшлися джерело і згенерована копія, і це варто зрозуміти, а не
закомітити.

Запускати після **кожної** правки англійського файлу. Перед комітом —
`git status`: у дифі має бути тільки те, що ви чіпали.

## Обмеження розмітки

Білд шукає пари регексом, а перемикач мов присвоює `textContent`. Тому:

- `data-en` і `data-ua` стоять **поруч, у цьому порядку, розділені рівно
  одним пробілом**. Зворотний порядок або два пробіли — пара не
  знайдеться;
- вміст елемента — **один текстовий вузол без вкладених тегів**. `<strong>`
  усередині перекладного абзацу зникне при першому ж перемиканні мови.
  Потрібен акцент — виносьте його окремим елементом зі своєю парою;
- у значеннях атрибутів **не можна лапок** `"`. Беріть «ялинки» або
  типографські;
- елемент має закриватися своїм тегом; самозакривні не працюють.

Інші атрибути можуть стояти і до пари, і після неї — це не заважає.

**Збій тихий, і це найнеприємніше.** Якщо пара не знайшлася, білд не
лається: він просто не підставляє український текст, і згенерована
сторінка віддається англійською. Перемикач у шапці при цьому працює
нормально — він читає атрибути окремо й на порядок не зважає. Тобто
клацанням EN/UA ви поламану пару **не побачите**. Побачите тільки
завантаженням `/ua/...` начисто: якщо там англійський текст — шукайте
пару.

Перевірити свою розмітку можна руками:

```bash
node -e '
const re=/(<([a-z][\w-]*)(?:\s[^>]*)?\sdata-en="[^"]*"\sdata-ua="([^"]*)"(?:\s[^>]*)?>)([^<]*)(<\/\2>)/gi;
const s=require("fs").readFileSync("ua/rates/index.html","utf8");
let n=0; for(const m of s.matchAll(/data-ua=/g)) n++;
let ok=0; s.replace(re,(...a)=>{ if(a[4].trim()===a[3]) ok++; return a[0]; });
console.log("пар:",n,"| перекладено:",ok,"| не спрацювало:",n-ok);
'
```

Тег `<html>` мусить лишатися рівно таким: `<html lang="en" data-theme="...">`.
Тему ставить білд за маршрутом (`light` для фото й дизайну, `night` для
відео, `green` для решти) — руками її не міняйте.

Ще одна дрібниця: білд робить глобальну заміну `>Contacts<` на
`>Work terms<`. Не пишіть слово `Contacts` як видимий текст — воно
перетвориться. `Contact` в однині безпечне.

## Мова за замовчуванням

Згенерована сторінка має віддаватися українською і не перемикати себе
назад. Джерела використовують дві форми скрипта, і білд закріплює обидві:
довгу `setLang(detect(), false)` регексом, коротку `L(D(),false)` —
буквальною заміною. Якщо додаєте сторінку з новою формою виклику —
допишіть заміну, інакше українська адреса віддаватиме англійську для
кожного, у кого браузер не український.

## Дизайн-система

Уся геометрія — у `photo/photo.css` (розділи) і в `<style>` всередині
`index.html` (головна). Обидва набори тримають ту саму 12-колонкову сітку.

Вертикалі, на яких стоїть усе:

| що | де |
|---|---|
| підпис розділу | перша колонка, по її правому краю, `height:0` |
| номер рядка і початок лінійки | `--col2` |
| основний вміст | третій трек |
| права колонка | дев'ятий трек |

Лінійка малюється на **верхній** межі рядка (`::before`), а не під ним —
тоді під останнім рядком її немає сама собою.

Кеглі — шість щаблів (`--fs-chrome` … `--fs-name`), ваги — три (400 текст,
600 капітель, 700 вітрина). Не заводьте проміжних.

Охра (`--pencil`) означає «сюди можна натиснути»: ховер, фокус, виділення.
На неінтерактивних рядках її не буває.

## Пастка з сіткою

У `repeat(12,1fr)` трек має мінімум за вмістом. Номер рядка стоїть у першій
колонці з полем `margin-left:var(--col2)`, і це роздуває перший трек зі 78
до ~183 px, а решту стискає з 78 до ~68. Тому основний вміст на сайті
стоїть на **372 px, а не на 277**, як показав би чистий розрахунок.

Це поведінка всього сайту, а не хиба однієї сторінки. На `/rates/` її
відтворює розпірка `.tbody::before` — інакше розділи з номерами й розділи
без них рахували б треки по-різному й сторінка мала б два ліві краї.

Не «виправляйте» це через `minmax(0,1fr)` на одній сторінці: вона з'їде
відносно решти сайту. Або скрізь, або ніде.

## Ціни

Живуть текстом у `rates/index.html`. Гривня і долар — **незалежні рядки**
в `data-ua` і `data-en`, автоматичного зв'язку між ними немає.

Долари рахувалися так: `грн ÷ 45 × 1.15`, далі вгору — до цілого долара
нижче $20, до п'ятірки до $100, до десятки вище. 45 замість ринкового
курсу і 15 % зверху покривають конвертацію й комісії, бо банк не дає
міжбанк, а Payoneer і банк-отримувач беруть своє.

Міняєте курс — перерахуйте **всі вісім** позицій, інакше прайс поїде
внутрішньо.

## Робочий цикл

```bash
git pull --ff-only            # головний checkout часто відстає
# правки в англійському файлі
node scripts/build-ukrainian-pages.mjs
git status                    # у дифі тільки очікуване
git add -A && git commit
git push origin main          # сайт оновиться за ~30 с
```

## Відомі хиби, які ніхто не чіпав

- `.cats` роздуває перший трек трохи інакше за `.specs` (у номера немає
  `min-width:3ch`), тож підписи контактів стоять на 366 замість 372.
  Різниця 6 px, на око непомітна, але вона є на всіх сторінках розділів.
- Доларові ціни оновлюються руками. Курс поїде — прайс не помітить.
